# Resume RAG Chatbot

## Overview
AI-powered Resume Question Answering System using RAG.

## Features
- Upload Resume PDF
- Semantic Search using FAISS
- Retrieval-Augmented Generation
- Groq LLM Integration
- Streamlit UI
- Chat History

## Tech Stack
- Python
- Streamlit
- LangChain
- FAISS
- Groq
- Sentence Transformers

## Run Locally

pip install -r requirements.txt

streamlit run app.py
